# 📊 Spreadsheet Automation

A Python project developed to automate spreadsheet-related tasks and practice data manipulation with Pandas and Excel files.

## 📌 About the Project

The program works with spreadsheet data and automates operations that would otherwise need to be performed manually.

The project was created as part of my programming learning roadmap, with a focus on Python, Pandas, and Excel automation.

## 🚀 Features

- Read Excel spreadsheets;
- Process spreadsheet data;
- Work with columns and DataFrames;
- Automate spreadsheet operations;
- Export processed data back to Excel;
- Generate useful information from the data.

## 🛠️ Technologies

- Python
- Pandas
- Excel

## 📚 Concepts Practiced

During the development of this project, I practiced:

- `pandas`;
- `read_excel()`;
- `to_excel()`;
- DataFrames;
- Working with columns;
- Reading and manipulating spreadsheet data;
- Exporting data to Excel;
- Basic data processing with Python.
